TC-01 / ABOUTPASS

I think like a tester and build like a product owner.

I’m a software engineer at Capgemini, working in quality engineering — designing test cases, running integration and acceptance cycles, and making sure a release holds up before people depend on it. I grew up in Jodhpur, Rajasthan, finished my MCA at JECRC University in 2025, and now live in Navi Mumbai.

Outside work I run Protein Plate, a cloud kitchen, and I’m the person behind its entire software platform. To be plain about it: the code was written by AI coding agents — Claude Code, Google Antigravity and OpenAI Codex. My part was everything around the code: deciding what to build, guiding the agents, stepping in where they fell short, testing every flow, and running it live for real customers.

I call that AI-directed development. My strength isn’t deep hand-coding; it’s product thinking, and knowing exactly how software breaks.
